# 손 제스처 최적화안 (2026-11-11)

전제: 우클릭 없음. 제스처는 **이동 · 좌클릭(엄지를 검지에 붙이기) · 더블클릭 · 드래그 · 스크롤** 다섯 가지만 둔다.

> 변경 (2026-11-11): 엄지를 손바닥 안으로 접는 동작이 어렵다는 피드백에 따라, 좌클릭을 "엄지를 검지 옆면(또는 끝)에 붙이기"로 바꿨다. 판정 값은 `thumbIndexRatio`(엄지 끝 ~ 검지 꺾은선 거리 / 손 크기)이고 누름 0.25 미만, 뗌 0.40 초과다. 아래 내용의 "엄지 접기"는 모두 "엄지 붙이기"로 읽는다.
참고한 구현: mac-hand-mouse(Swift/Vision), Skeleton_Engine, HandTrack-MacControl(Python/MediaPipe), visionOS 제스처 가이드.

- 이 저장소 코드에는 우클릭 이벤트를 만드는 부분이 없다(`rightMouseDown` 검색 0건).

- 조치: 이전 빌드를 지우거나 이름을 바꾸고, 이 저장소에서 `./build.sh run`으로 실행한다.

## 2. 최적화안

### P0: 오작동을 줄이는 수정 (작고 독립적)

1. **시간 기반 확정 (A, B)**
   - 엄지 무장: "펴짐 4프레임" → "펴짐 3프레임 이상 **그리고** 0.12초 이상"
   - 엄지 접기 진입: 접힘이 2프레임 이상 **그리고** 0.05초 이상 이어져야 누름으로 본다(한 프레임짜리 오인식 차단)
   - 스크롤 진입: "자세 3프레임" → "3프레임 **그리고** 0.10초"
   - 프레임 간격이 0.12초를 넘으면 진행 중이던 확정 단계를 리셋한다(누른 상태 자체는 기존 워치독 1.2초가 담당)
2. ~~**스크롤 클램프 제거 + 튐 방지 (C, D)**~~ → 조이스틱 스크롤로 대체됨 (2026-11-11). 기준점(검지·중지 MCP 중점) 대비 손 이동 방향·거리로 속도를 정하고, 240Hz tick에서 서브픽셀 누적해 배출한다. 정지 구간 0.25 palm, 속도 = 1600 × (초과 거리)^1.6 px/s, 상한 4000 px/s.
   - 스크롤 dy는 손 Y의 프레임 간 차이(정규화 좌표)로 계산하고 ROI 클램프를 뺀다.
   - 기준점은 검지·중지 끝 평균 대신 **검지·중지 MCP 평균**을 쓴다(손 전체 움직임 = 스크롤, 손가락 떨림은 무시).
   - `|dy| > 0.08`(정규화 좌표)인 프레임은 불연속으로 보고 버린다. 프레임당 스크롤을 ±60px로 제한한다.
3. **드래그 거리 정규화 (G)**
   - `handMoveDist`를 화면 px 대신 "손 이동량 / palmScale"로 계산한다(예: 진입 0.25 palm).

### P1: 조작감

4. **재앵커 (E, F)**
   - 스크롤이 끝나거나 손을 다시 잡으면, 화면 커서는 그 자리에 두고 "현재 손 위치 = 현재 커서"가 되도록 매핑 오프셋을 다시 잡는다.
   - 오프셋은 이후 일반 이동 중에 천천히 0으로 되돌려, 손 위치와 화면 위치가 영구히 어긋나지 않게 한다.
5. **커서 Y를 검지 MCP 쪽으로 (H)**
   - 커서 좌표 = 검지 끝과 검지 MCP를 섞은 점(예: X는 끝 100%, Y는 끝 40% + MCP 60%).
   - 엄지를 접을 때 생기는 검지 흔들림이 줄어 롤백 의존도가 낮아진다. 메뉴 토글로 A/B 비교한 뒤 기본값을 정한다.
6. **HUD 피드백 (J)**
   - 엄지가 다가오는 동안(`foldRatio < 0.60`) 커서 위치 HUD에 링을 채우고, 누름 상태가 되면 초록, 드래그 상태가 되면 파랑으로 표시한다.
   - 무장되지 않은 상태(엄지를 접은 채 진입)에서는 "엄지를 한 번 펴세요"라고 안내한다.

### P2: 보정 도구

7. **랜드마크 기록·재생 (I)**: 기존 [IMPROVEMENTS.md](IMPROVEMENTS.md) #10과 같다. 엄지 접기 임계값을 실제 손 데이터로 맞추는 데 필요하므로 P1 작업 전에 해두면 좋다.
8. **엄지 임계값 자동 보정**: 시작할 때 3초 동안 "엄지 펴기 → 접기"를 2회 시켜 `foldRatio`의 펴짐·접힘 값을 재고, 그 사이 값으로 `enter/exit`를 정한다(사람마다 엄지 길이와 유연성이 다름).
